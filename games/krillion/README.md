# Krillion

Krillion is a standalone, offline trivia game for Android and iPhone. Both native projects bundle [the same HTML game](web/index.html). Each installed app stores prompt history on its own device.

- [Android debug APK](Krillion-debug.apk) for Android 8.0 and newer. This build is signed for testing.
- [Android project and build instructions](android/README.md).
- [iPhone Xcode project and build instructions](ios/README.md). Installing on a physical iPhone requires Xcode on macOS and an Apple signing team.

These projects launch Krillion directly. SnoozeLose can integrate the game once the team defines the alarm and puzzle interface.
