# SnoozeLose Final Product

This is the submitted iPhone app source for SnoozeLose v1.9.1, build 28.

Open [SnoozeLose.xcodeproj](app/SnoozeLose.xcodeproj) in Xcode, select the SnoozeLose target, and choose your development team under Signing & Capabilities. The target has a minimum deployment version of iOS 16. Use an Xcode version with the iOS 26 SDK to build with AlarmKit support.

The alarm game picker offers Perception Set and Word Guess. Krillion appears as unavailable in this build. The supplied Expo reference sits outside the iPhone target. [Game picker notes](app/GAME_PICKER_v191.md)

This submission was checked for Xcode project structure and bundled resources. A full Xcode build and alarm delivery on an iPhone remain unverified.
